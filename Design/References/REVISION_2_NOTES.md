User requested a larger map, multiple assault options at each point, visible troop placements and trenches on the active American front.

Current authoritative files: frontline-plan-v2.svg / .png, map-layout.json and PHASE_1_BRIAR_COUNTY.md. The SVG is a purpose-built vector game-design schematic, rendered locally using Sharp. Its reproducible generator is Design/tools/revise_map.py. It is not a generated terrain painting.

The expanded painted-map request failed with a network error. A separate image-generation request including the troop/trench overlay was rejected by the image tool's safety system; it was not retried. The schematic delivers the requested placement information using labeled unit icons. The original painted map remains a superseded composition reference; no new painted concept is claimed.

Visual inspection checked legend, route continuity, scale and unit visibility. Farm labels were moved clear of the trench lines, and E4/E7 reserves were repositioned behind their local defenses. Final navigation and combat validity require graybox playtesting.
